# M01 SocialTensionGraph：社会张力规划生成

## 一句话提案

在写 Punchline 前显式构建人物关系、权力、体面、潜台词和情绪冲突图，让模型从“语言模仿”转向“社会情境推理”。

## 摘要

中文生活幽默经常依赖一句话之外的关系信息：同样的表达，由老板、朋友、对象或陌生人说出来，含义完全不同。SocialTensionGraph 把场景中的角色和社会事实表示为图，再从图中寻找可被幽默压缩的张力路径。该方法的核心贡献不是增加推理长度，而是引入可解释、可干预和可做反事实实验的中间表示。

## 图表示

节点包括：

- 人物与群体。
- 公开目标与私人目标。
- 社会规则和角色期待。
- 物体、事件和文化锚点。
- 体面、秘密和情绪状态。

边包括：

- 权力高于或依赖。
- 想让对方相信。
- 实际知道但不能明说。
- 违反社会规则。
- 威胁某人的体面。
- 表面行为掩盖真实情绪。
- 可通过幽默机制重新解释。

## 生成流程

```text
Scene Parser
-> SocialTensionGraph
-> Contradiction Miner
-> Humor Target Selector
-> Mechanism Planner
-> Punchline Writer
-> Traceability Critic
```

`Contradiction Miner` 寻找“表面目标与私人目标冲突”“规则与现实冲突”“权力与语言礼貌冲突”等路径。Writer 只能使用图中可追溯信息，避免凭空随机反转。

## 研究问题

- RQ1：图表示是否提升场景贴合、潜台词准确度和人类幽默偏好？
- RQ2：哪些节点和边对不同幽默机制最关键？
- RQ3：显式图是否比自由 CoT 更稳定、更可解释？
- RQ4：修改权力、关系或私人目标后，系统能否产生符合反事实的新 Punchline？

## 方法变体

- LLM 直接输出 JSON 图。
- 规则与 LLM 混合校验图。
- 图神经网络编码加语言模型解码。
- 检索相似图结构但不同表面场景。
- 图路径约束的 Beam Search。
- 将图作为隐藏计划，仅输出最终文本。

## 实验与消融

对比原始场景、自然语言分析、自由 CoT、结构化表格和图表示。分别删除权力边、体面节点、私人目标、社会规则和文化锚点，测量质量下降。构造同场景角色互换、上下级互换和熟悉度变化的反事实测试。

## 评价

除人类成对胜率外，评价图标注准确率、Punchline 对图路径的可追溯率、反事实一致性、结构多样性和错误可诊断性。最终输出不能显示分析过程或解释笑点。

## 预期贡献

1. 一个适合中文生活幽默的社会情境表示。
2. 一种可干预、可做因果消融的生成方法。
3. 证明“理解关系”是否比“增加模型规模”更重要。
4. 为评论、共情表达和高价值文章提供可迁移的社会语用底座。

## 风险与伦理

图可能把复杂人际关系过度简化，也可能由模型制造虚假潜台词。应允许不确定边和多种解释，并把“场景信息不足，主动弃权”设为合法输出。
